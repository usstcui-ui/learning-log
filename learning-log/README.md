# 学习日志

个人自用的学习打卡与笔记工具。纯前端运行，数据保存在浏览器本地（IndexedDB），不上传任何服务器。

设计文档见 `docs/`：

- `01-需求文档.md` 功能清单、技术选型、里程碑、验收标准
- `02-页面结构.md` 路由、页面区块、交互细节、视觉规范
- `03-数据模型.md` 表结构、索引、统计规则、导入导出格式

## 运行

```powershell
npm.cmd install
npm.cmd run dev
```

> 如果 PowerShell 提示「禁止运行脚本」，请使用 `npm.cmd` 而不是 `npm`，或者以管理员身份执行
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`。

打开 http://localhost:5173 。

## 数据安全

数据只存在当前浏览器的 IndexedDB 中：

- 首次访问会申请持久化存储，降低被浏览器清理的概率
- **清缓存、换浏览器、换设备都会导致数据不可见**
- 请在设置页定期「导出全量 JSON」备份，CSV 用于表格查看与交换
