# 学习记录网站 · 页面结构

> 配套文档：`01-需求文档.md`（功能定义）、`03-数据模型.md`（表结构与统计规则）
> 本文档描述**路由、全局框架、每个页面的区块与交互**，可直接作为开发与切图依据。

---

## 1. 路由表

| 路由 | 页面 | 组件 | 说明 |
| --- | --- | --- | --- |
| `/` | 首页 | `pages/dashboard` | 默认落地页 |
| `/checkin/new` | 新建打卡 | `pages/checkin` | 支持 `?date=` `?duration=` 预填（计时器跳转用） |
| `/checkin/:id/edit` | 编辑打卡 | `pages/checkin` | 同组件，`mode=edit` |
| `/checkins` | 打卡记录 | `pages/checkins` | 支持 `?tag=` `?q=` `?date=` 查询参数 |
| `/stats` | 统计 | `pages/stats` | 支持 `?range=7d\|30d\|90d\|year` |
| `/notes` | 笔记列表 | `pages/notes` | 支持 `?q=` |
| `/notes/new` | 新建笔记 | `pages/note-editor` | 支持 `?checkInId=` |
| `/notes/:id` | 笔记详情 | `pages/note-editor` | 默认只读展示，点「编辑」切换编辑态 |
| `/settings` | 设置 | `pages/settings` | 内部分区，锚点滚动 |
| `*` | 404 | `pages/not-found` | 引导回首页 |

**备注**：笔记详情不做独立只读页，用同一组件的编辑/预览双态，减少代码量与跳转层级。

## 2. 全局框架

### 2.1 布局

**桌面端（≥1024px）**：左侧固定侧边栏 240px + 主内容区（最大 1080px 居中，左右留白）。

```
┌────────────┬──────────────────────────────────────┐
│  学习日志   │                                      │
│            │                                      │
│  ▸ 首页     │            主内容区                  │
│  ▸ 记录     │                                      │
│  ▸ 笔记     │                          ┌────────┐ │
│  ▸ 统计     │                          │ 计时器  │ │
│  ▸ 设置     │                          └────────┘ │
│            │                                      │
│ [+ 新建打卡]│                                      │
└────────────┴──────────────────────────────────────┘
```

**移动端（<768px）**：顶部精简标题栏（页面名 + 右侧操作）+ 底部 Tab 栏 5 项 + 全局悬浮「+」按钮（新建打卡）。

```
┌──────────────────────────┐
│ 首页              [搜索]  │
├──────────────────────────┤
│                          │
│        内容滚动区         │
│                          │
│                    ╭───╮ │
│                    │ + │ │
│                    ╰───╯ │
├──────────────────────────┤
│ 首页  记录  笔记  统计 我的│
└──────────────────────────┘
```

- 底部 Tab：首页 / 记录 / 笔记 / 统计 / 设置（"我的"即设置）
- 悬浮按钮只在非打卡页显示，避免重复入口
- 计时器在移动端挪到右上角图标，展开为全屏抽屉

### 2.2 导航高亮规则

- `/` 精确匹配首页
- `/checkin/*` 归入「记录」高亮
- `/notes/*` 归入「笔记」
- `/stats/*` 归入「统计」
- `/settings/*` 归入「设置」

### 2.3 全局常驻元素

| 元素 | 位置 | 行为 |
| --- | --- | --- |
| 计时器 | 桌面右下角 / 移动端右上角 | 未运行时为图标；运行中显示 `25:13` 与呼吸动效；点击展开面板 |
| Toast | 顶部居中 | 保存成功、删除成功、导出完成，3 秒自动消失 |
| 确认弹窗 | 居中遮罩 | 删除、覆盖导入、清空数据 |
| 快捷键（桌面） | — | `N` 新建打卡、`/` 聚焦搜索、`Ctrl+Enter` 提交表单、`Esc` 关闭弹窗 |

### 2.4 页面状态矩阵

所有数据页面统一处理四种状态，不出现"白屏转圈"：

| 状态 | 表现 |
| --- | --- |
| 加载中 | 骨架屏（卡片灰块或图表灰块），不用居中 spinner |
| 空数据 | 插画 + 一句说明 + 主操作按钮（见 2.5） |
| 无结果 | "没有匹配的记录" + 「清除筛选」 |
| 错误 | 错误提示 + 「重试」；存储不可用时提示"浏览器存储不可用，请检查隐私模式" |

### 2.5 空状态文案

| 页面 | 文案 | 主按钮 |
| --- | --- | --- |
| 首页（无任何打卡） | 还没有打卡记录，今天开始记一笔？ | 新建打卡 |
| 打卡记录 | 没有找到打卡记录 | 新建打卡 / 清除筛选 |
| 笔记 | 还没有笔记，写下第一篇 | 新建笔记 |
| 统计 | 攒够几条打卡后，这里会长出图表 | 新建打卡 |
| 标签库为空（打卡页） | 先创建一个标签，比如「算法」 | 新建标签 |

```

│                                                      │

│ 学习内容 *                        [ 套用模板 ▾ ]      │

│ │ 第三章 动态规划，看了 3.1-3.4                     │ │
│ │                                                  │ │

│ 收获                                                  │

│ │ 理解状态转移方程的含义                            │ │
│ └──────────────────────────────────────────────────┘ │
│                                                      │
│ 疑问                                                  │
│ ┌──────────────────────────────────────────────────┐ │
│ │ 为什么初始状态要设成 -∞                           │ │
│ └──────────────────────────────────────────────────┘ │
│                                                      │
│ 下一步                                                │
│ ┌──────────────────────────────────────────────────┐ │
│ │ 明天做 3 道区间 DP 题                             │ │
│ └──────────────────────────────────────────────────┘ │

│              [ 存草稿 ]        [ 提交打卡 ]           │

```

移动端：日期与标签一行，时长一行，四个文本框纵向排列，底部吸底两个按钮。

### 4.2 字段规则

| 字段 | 控件 | 校验 | 备注 |
| --- | --- | --- | --- |
| 日期 | 日期选择 | 必填；不得晚于今天；不早于 30 天前 | 晚于今天的选项置灰并提示"不能记录未来" |
| 标签 | 多选 chips + 新建 | 至少 1 个 | 输入回车直接创建新标签，颜色自动分配 |
| 时长 | 数字输入 + 快捷 chip | 必填；1–1440 的整数 | 快捷 chip 点击后填入并高亮 |
| 学习内容 | textarea | 必填，≤ 2000 字 | 计数显示 `128/2000` |
| 收获 / 疑问 / 下一步 | textarea | 选填，各 ≤ 2000 字 | 空着不显示占位文字以外的提示 |
| 图片 | 上传区 | ≤ 6 张，单张压缩后 ≤ 500KB | 上传中显示进度遮罩 |

### 4.3 模板交互

1. 点「套用模板」→ 下拉菜单，列出内置模板与自定义模板
2. 选中后，把模板文本按段落填入四个字段：

| 模板段落 | 填入字段 |
| --- | --- |
| `章节 / 内容：` 之后 | 学习内容 |
| `学会：` 之后 | 收获 |
| `疑问：` 之后 | 疑问 |
| `下次计划：` 之后 | 下一步 |

3. 若任一目标字段已有内容，弹确认：「套用模板会覆盖当前填写内容，继续？」
4. 模板文本以空行分隔段落，解析时按行首关键字匹配；未匹配的段落整段放入「学习内容」

### 4.4 草稿机制

| 时机 | 行为 |
| --- | --- |
| 任一字段变化后 2 秒 | 写入 `drafts` 表，标题栏显示「草稿已保存 · 刚刚」 |
| 打开新建页时存在草稿 | 静默恢复，并在标题栏提示「已恢复上次草稿」+ 「丢弃草稿」链接 |
| 提交成功 | 删除对应草稿 |
| 编辑既有打卡 | 不写草稿表；直接修改并在离开时提示未保存 |

### 4.5 计时器跳转

从计时器点「生成打卡」→ `/checkin/new?duration=45&date=今日`，时长预填并高亮，光标自动聚焦「学习内容」。

### 5.2 交互细节

| 元素 | 行为 |
| --- | --- |
| 搜索框 | 输入即筛（300ms 防抖），匹配 内容 / 收获 / 疑问 / 下一步 / 标签名，命中词高亮 |
| 标签筛选 | 多选，**并集**语义（命中任一标签即显示）；再次点击取消 |
| 时间筛选 | 单选，与标签筛选、搜索条件为**与**关系 |
| 分组头 | 按日期倒序分组，右侧显示当日合计时长与条数 |
| 卡片点击 | 进入 `/checkin/:id/edit` |
| `⋯` 菜单 | 编辑、复制为新打卡、删除 |
| 删除 | 弹窗确认，软删除，Toast「已删除 · 撤销」（5 秒内可撤销） |
| 列表加载 | 首屏 20 条，滚动到底自动加载下一批，底部显示「没有更多了」 |
| 筛选条件 | 同步到 URL 查询参数，刷新后保持 |

### 5.3 卡片信息优先级

1. 时长（最醒目，右对齐，等宽数字）
2. 标签（色点 + 名称）
3. 内容首行
4. 收获摘要（灰色，1 行）
5. 附件 / 关联笔记标记（小图标 + 数字）

### 6.2 区块规则

| 区块 | 规则 |
| --- | --- |
| 区间切换 | 本周（周一起）、本月、近 30 天、本年；切换后所有图表联动 |
| 总时长 | 区间内打卡时长求和，显示 `X 小时 Y 分钟`，超过 100 小时只显示 `X 小时` |
| 日均 | 总时长 ÷ 区间天数（含无记录日），四舍五入到分钟 |
| 打卡天数 | 有 ≥1 条打卡的自然日数量 |
| 出勤率 | 打卡天数 ÷ 区间天数，取整百分比 |
| 折线图 | 按日聚合，**无记录日补 0**，保证曲线连续；Y 轴上限取区间最大值向上取整到 30 的倍数 |
| 按周模式 | 区间 ≥ 90 天时默认按月/周聚合，避免点过密 |
| 标签占比 | 多标签打卡**按时长均分**到各标签（见数据模型 4.2）；Top 8 之外合并为"其他" |
| 环形图 | 中心显示总时长；hover 某段高亮对应排行行 |
| 月热力图 | 月历布局，周一起始；格子显示日期数字，按 5 档着色；点击某天跳转记录页 |
| 图表空态 | 区间内无数据时图表区显示「该区间还没有打卡记录」 |

### 6.3 图表技术细节

- 折线图使用平滑曲线但**不做数据插值**，只连接真实点，0 值处贴底
- 无数据点不显示圆点，避免视觉噪声
- 所有图表使用主题色令牌，深色模式下网格线用 `--border` 而非白色
- 移动端图表高度降到 180px，X 轴标签自动抽稀（每 5 天一个）

- 卡片显示：标题、正文纯文本摘要（2 行，去掉 Markdown 符号）、标签、关联打卡日期

### 7.2 编辑 / 详情

**桌面端：左右分栏**

```
┌──────────────────────────────────────────────────────┐
│ ← 笔记        [标题输入框]     [关联打卡▾]  [保存] [⋯] │
├───────────────────────┬──────────────────────────────┤
│ Markdown 源码          │ 预览                          │
│                       │                              │
│ ## 状态定义            │ 状态定义                      │
│ $f[i] = ...$          │ f[i] = ...（公式渲染）        │
│                       │                              │
└───────────────────────┴──────────────────────────────┘
```

**移动端：页签切换（编辑 / 预览）**，底部吸底「保存」。

| 编号 | 交互 | 说明 |
| --- | --- | --- |
| 1 | 标题输入 | 单行，空标题时保存自动取正文首行前 20 字 |
| 2 | 工具栏 | 粗体、标题、列表、链接、代码、公式、图片（可选） |
| 3 | 快捷键 | `Ctrl+B` 粗体、`Ctrl+I` 斜体、`Ctrl+S` 保存 |
| 4 | 自动草稿 | 每 2 秒写入草稿表，标题显示「草稿已保存」 |

| 6 | 保存 | 显式保存，Toast「已保存」；未保存离开时提示 |
| 7 | 删除 | 二次确认，软删除，返回列表 |

### 7.3 Markdown 支持范围

| 语法 | 支持 |
| --- | --- |
| 标题 `#`~`######` | 是 |
| 粗体 / 斜体 / 删除线 | 是 |

| 引用、分割线 | 是 |

## 9. 计时器

### 9.1 形态

| 状态 | 桌面 | 移动 |
| --- | --- | --- |
| 未启动 | 右下角圆形图标按钮 | 顶栏图标 |
| 运行中 | 胶囊形 `25:13` + 呼吸动效 | 顶栏胶囊 |
| 展开 | 右上浮层 320px | 全屏抽屉 |

### 9.2 面板

```
┌─────────────────────────────┐
│ 计时器                  [×] │
│                             │
│        25:13                │
│      正计时中                │
│                             │
│  [ 暂停 ]   [ 结束并打卡 ]   │
│                             │
│ 模式： ( 正计时 | 25 分钟 )  │
│ 标签： [ 算法 + ]            │
│ 备注： [ 继续做区间 DP    ]  │
└─────────────────────────────┘
```

### 9.3 规则

- "暂停"累加到 `accumulatedMs`；恢复时记录新的 `runningSince`
- "结束并打卡"：跳转 `/checkin/new?duration=⌈已用秒/60⌉`，标签与备注尽量预填
- 计时中关闭页面（刷新）：从存储恢复并重新计算，不丢时间
- 计时中离开页面：面板收起但继续计时，顶栏胶囊常驻
- 倒计时到 0：Toast + 提示音（可选）+ 自动跳转打卡页
- 同时只允许一个计时会话
